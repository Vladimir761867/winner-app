# Победитель

Игра-раннер на одном HTML-файле (Canvas 2D, без библиотек): герой не убегает от проблем, а побеждает их.

## Структура
- `index.html` — текущая версия (**Победитель 15**): 8 сюжетов (в т.ч. «Школа» и «Экскурсия»), у каждого уровня своя локация, 4 героя, живые боссы, перки, батуты, прыжок на врага. Открывается двойным кликом.
- `docs/Pobeditel_spec_dlya_razrabotchika.md` — ТЗ и описание всех 15 игр/версий.
- `archive/` — все предыдущие версии (`pobeditel.html` … `pobeditel14.html`).
- `AppStore_paket/` — заготовка для выпуска в App Store (Capacitor, иконка, тексты, политика, скриншоты). Нужны Mac с Xcode и аккаунт Apple Developer — см. `AppStore_paket/README_RELEASE.md`.

## Запуск
Откройте `index.html` в браузере (на телефоне — через ссылку на хостинг).
