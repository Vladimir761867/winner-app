# Победитель

Игра-раннер на одном HTML-файле (Canvas 2D, без библиотек и ассетов): герой не убегает от проблем, а побеждает их.

## Структура
- `index.html` — текущая версия игры (Победитель 9). Открывается двойным кликом в браузере.
- `docs/Pobeditel_spec_dlya_razrabotchika.md` — ТЗ, механики и данные для разработчика.
- `archive/` — предыдущие версии (`pobeditel.html` … `pobeditel8.html`).

## Запуск
Откройте `index.html` в браузере.
